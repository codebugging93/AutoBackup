#1

원본 폴더의 파일 이름의 집합 : A
대상 폴더의 파일 이름의 집합 : B
A, B에서 이름이 같은 파일의 집합 :
    A & B = S라 정의
이름은 같으나 내용이 다른 파일의 집합 : NS
    
즉 A와 B 사이에서 완전히 같은 파일의 집합은 S - NS이다.

복사할 파일:
    A - (S - NS)
    
삭제할 파일:
    B - (S - NS)


#2

A, B, A & B 의 원소의 개수가 같으면
A = B이다.

증명
n(A) = n(B) = n(A & B)
n(A) - n(A & B) = n(A - B) = 0
n(B) - n(A & B) = n(B - A) = 0

즉 A - B = B - A = 공집합

한편,
A - B = 공집합 ㅡ> A C B 이므로
A C B, B C A이고

A C B, B C A ㅡ> A = B 이므로
두 집합은 같다.
